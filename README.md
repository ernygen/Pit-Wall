# Pit Wall — Save to Table (Fully done with AI to help a friend)

The **complete Pit Wall app** (every page and feature of `Pit Wall.html`),
running on **your own Team Principal save files** instead of built-in data.

Upload your career's `season*.json` files once — the app persists them in the
browser and boots straight into the full experience. **Past seasons come
along automatically:** each save carries `season_history` with round-by-round
results, poles, points and teams, so a season 9 save loads all 9 seasons —
Hall of Fame, records and transfers light up across the whole career:

Home dashboard · Drivers · Teams · Transfers · Line-ups · Rounds · Calendar ·
Winners & Podiums · Championship fight · Analysis · Recap · Engines ·
Records · Tracks · Head to head · Hall of Fame · Compare seasons · Projection

…plus driver/team/track search (<kbd>/</kbd>), season switcher, light/dark
theme, phone/PC view, PNG export on every page, backup download/import,
and the game's own flags + team logos offline.

- Files are processed **locally in the browser only**, nothing is uploaded anywhere.
- Expected files: the `season*.json` files from the game's `saves` folder.
  Example: `season1.json`, `season2.json`, … Upload the seasons of
  **one career together**.
- Default Steam location:
  `E:\SteamLibrary\steamapps\common\Team Principal A Racing Manager\saves`

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
cd pitwall-site
npx serve .
# or
python -m http.server 8000
```

First run shows the upload view. **Season 1 starts in** sets the calendar year
of your first season (default 2001) — later seasons follow automatically
(S2 = year+1, …). Changing it later re-numbers every season via Apply year.
After loading saves the page reloads into the full app; your data stays in
the browser (localStorage + IndexedDB backup).

## Publish with GitHub Pages

1. Create a new GitHub repo (e.g. `pitwall`).
2. Upload/push this folder (except this README's build scripts if you like,
   but keep them — they make updates reproducible):

```bash
cd pitwall-site
git init
git add index.html parser.js upload.js assets.js flags logos .nojekyll README.md build_assets.py build_site.py
git commit -m "Pit Wall save-to-table site"
git branch -M main
git remote add origin https://github.com/USER/pitwall.git
git push -u origin main
```

3. On GitHub go to repo → **Settings → Pages** →
   **Deploy from a branch** → branch `main`, folder `/ (root)` → **Save**.
4. After a minute or two the site is live at:

```text
https://USER.github.io/pitwall/
```

Anyone opening that address uploads their own `season*.json` files and gets
the whole app. **Download backup** in the upload view exports everything as
one JSON that can be imported on another machine.

## Files

- `index.html` — **generated** full app (Pit Wall shell + CSS + app JS + loader).
  Do not edit by hand; rebuild with `build_site.py`.
- `build_site.py` — rebuilds `index.html` from `../Pit Wall.html`
  (run again after Pit Wall updates: `python build_site.py`).
- `parser.js` — save → Pit Wall `SEASONS` converter (browser + Node).
- `upload.js` — upload view, persistence, team-color/flag CSS generation.
- `assets.js` — flag/logo manifests (generated by `build_assets.py`).
- `flags/` — the game's own flag PNGs (`ui/assets/flags`, full coverage, offline).
- `logos/` — the game's own team-logo PNGs (matched per team, offline).
- `build_assets.py` — re-builds `flags/`, `logos/` and `assets.js` from a game install.
- `.nojekyll` — makes Pages serve files as-is.

How it fits together: the app code is the original Pit Wall code untouched
(except a 2-line guarded boot for empty data). Your saves are converted to
the exact `SEASONS` schema it expects, team colors are injected as
`.tc-<id>` rules, missing flag codes as `.fl-<cc>` rules pointing at the
local game files, and team logos are served through the `window.BADGES` hook
the app already supports (PNG export included).

## Adding new teams (new career / new mods)

If a team shows initials instead of its logo, re-run the asset builder
against your game install — it scans your saves, finds each logo across all
data packs and updates the manifests:

```bash
cd pitwall-site
python build_assets.py
python build_assets.py --game "PATH\\TO\\Team Principal A Racing Manager" --saves "PATH\\TO\\saves"
```

Then commit/push the new `logos/` + `assets.js`.

## Scoring

Base system `25-18-15-12-10-8-6-4-2-1` (top 10). Like the original app, all
derived tables are computed from race positions with the season's scoring
table. `Ret/DNF` → `R`, `DNQ` stays, races a driver missed stay blank.

## Note

Don't mix `season1.json` files from **different careers** in one upload —
their `season_no` values collide and only the fullest one is kept. Upload one
career's files at a time.

The `flags/` and `logos/` art is extracted from your local game install for
personal/fan use.
